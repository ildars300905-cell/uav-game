ОПЕРАТОР БПЛА — веб-приложение (PWA)

Все файлы из этой папки нужно выложить на любой бесплатный хостинг с HTTPS
(GitHub Pages, Netlify, Vercel и т.п.). Файлы должны лежать рядом, в одной папке.

После этого откройте адрес сайта на телефоне:
  Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран»
  iPhone (Safari):  кнопка «Поделиться» → «На экран „Домой“»

Игра откроется на весь экран с собственной иконкой и после первого запуска
будет работать без интернета.
